رسیت‌ویژن Core

عکس رسید را بفرست، متنش را تحویل بگیر. بک‌اند Spring Boot + موتور Tesseract (فارسی/انگلیسی) + دیتابیس H2 — بدون نصب Java و Maven، فقط با Docker بالا می‌آید.

★ 3 استارJava 17 / Spring BootTesseract OCRDocker

✓ saved to H2 (persistent volume)

✨ قابلیت‌ها

📤
آپلود API

دریافت تصویر رسید با multipart/form-data.

🔍
OCR فارسی+انگلیسی

استخراج خودکار متن با Tesseract.

💾
ذخیره‌سازی

دیتابیس H2 با persist روی دیسک + کنسول وب.

🐳
تک‌دستوری

بدون نصب پیش‌نیاز، فقط Docker کافی است.

📡
REST تمیز

GET لیست، GET تکی و POST آپلود.

⚙️
کانفیگ محیطی

پورت و آدرس دیتابیس با ENV قابل تغییر.

🚀 اجرای سریع

با Docker (پیشنهادی)
docker build -t receiptvision .
docker run -p 8080:8080 -v receipt-data:/data receiptvision
دسترسی

API روی http://localhost:8080 و کنسول دیتابیس روی /h2-console

اجرای توسعه‌دهنده (بدون داکر)
# نیاز: Java17 + Maven + tesseract-ocr-fas
mvn spring-boot:run
