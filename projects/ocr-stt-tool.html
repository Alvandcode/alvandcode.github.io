ابزار OCR + گفتار به متن

یک ابزار چندسکویی (Windows / macOS / Linux / Android / iOS): استخراج متن از عکس و PDF با Tesseract، تبدیل صدا به متن فارسی و انگلیسی، با رابط CLI و اپ گرافیکی Kivy.

★ 4 استارPythonTesseractKivyMIT
⬇ دریافت از گیت‌هاب
cli — demo
$ python -m app.cli image sample.png
✓
سلام دنیا! این متن از تصویر استخراج شد.
$ python -m app.cli audio voice.wav --lang fa-IR
→ متن فارسی پیاده‌سازی شد ✓
$ python -m app.gui_kivy
# رابط گرافیکی باز می‌شود…

✨ قابلیت‌ها

🖼️
OCR تصویر

پشتیبانی از فارسی و انگلیسی با موتور Tesseract.

📄
استخراج از PDF

خواندن متن PDFهای اسکن‌شده و متنی.

🎙️
گفتار به متن

پشتیبانی از fa-IR و en-US (نیازمند اینترنت).

💻
دو رابط

CLI سریع برای توسعه‌دهنده + GUI با Kivy برای همه.

📱
موبایل

بیلد APK با Buildozer و بیلد iOS با Kivy-iOS.

🧩
ماژولار

ساختار core جدا برای توسعه آسان قابلیت جدید.

🚀 نصب و اجرا

۱. نصب وابستگی‌ها + Tesseract
pip install -r requirements.txt
# linux: sudo apt install tesseract-ocr tesseract-ocr-fas
# mac: brew install tesseract
۲. اجرای CLI
python -m app.cli image examples/sample.png
python -m app.cli pdf examples/sample.pdf
python -m app.cli audio examples/sample.wav --lang fa-IR
۳. بیلد موبایل / دسکتاپ
# android: buildozer -v android debug
# desktop: pyinstaller app/cli.py --onefile
